## 📝 Patrón Estándar Establecido

Para configurar un componente completamente:

### TypeScript:

```typescript
@Input() variant: string = 'primary';
```

### SCSS:

```scss
@use '../styles/mixins' as shared; // o '../../styles/mixins'

.component-class {
  background: var(--theme-bg, /* fallback */);
  color: var(--theme-color, /* fallback */);
  // ... otros estilos base

  @include shared.apply-all-variants('variant-');
  // O para prefijo específico: 'component-'
}
```

### HTML:

```html
<!-- Opción 1: ngClass con array -->
<div [ngClass]="['variant-' + variant, variant]">
  <!-- Opción 2: Computed signal -->
  <div [class]="componentClasses()">// donde componentClasses = computed(() => ['container', `variant-${this.variant()}`])</div>
</div>
```

### Editor Template:

```html
<div *ngSwitchCase="'component-type'">
  <div
    (click)="selectElement($event, { 
    id: section.id + '_component', 
    sectionId: section.id,
    content: section.content, 
    type: 'component-type', 
    _original: section.content 
  })"
  >
    <lib-component [variant]="section.content['variant'] || getVariant(section.id)" [title]="section.content['title'] || 'Default Title'" [customStyles]="section.styles || {}"></lib-component>
  </div>
</div>
```
